# GitHub Repository Analysis Dashboard

## Project Overview
This Power BI dashboard provides insights into GitHub repository performance, popularity, and development trends.

## Key Features
- Repository Performance Analysis
- Stars and Forks Analysis
- Programming Language Distribution
- Contributor Insights
- Repository Activity Tracking

## Tools Used
- Power BI
- Microsoft Excel / CSV
- Data Modeling
- DAX
- Data Visualization

## Dashboard Insights
- Top repositories by stars
- Fork distribution analysis
- Most used programming languages
- Repository growth trends
- Contributor activity metrics
